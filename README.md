# Network Security Fundamentals

## 📌 Overview

This repository contains a structured learning report on **Network Security Fundamentals**, focusing on understanding network communication, common cybersecurity threats, and essential security mechanisms used to protect organizational network infrastructure.

The objective is to develop foundational knowledge of network security concepts, protocols, devices, vulnerabilities, and security best practices through theoretical learning and practical exercises.

## 🎯 Objectives

- Understand network security fundamentals and their importance.
- Learn TCP/IP architecture and commonly used network protocols.
- Understand DNS, HTTP, HTTPS, and TLS.
- Study the roles of routers, switches, firewalls, and proxies.
- Identify common network threats and attack techniques.
- Understand basic network security controls.
- Explore practical network security exercises.
- Develop awareness of network security best practices.

## 📚 Topics Covered

### 1. Network Security Fundamentals
- Introduction to Computer Networks
- Importance of Network Security
- CIA Triad (Confidentiality, Integrity, Availability)

### 2. Network Protocols
- TCP/IP Model
- TCP and UDP
- IP Addressing
- DNS
- HTTP and HTTPS
- SSH, FTP, DHCP and SMTP

### 3. Network Infrastructure
- Routers
- Switches
- Firewalls
- Proxies
- Intrusion Detection Systems (IDS)
- Intrusion Prevention Systems (IPS)

### 4. Common Network Threats
- Phishing
- IP and DNS Spoofing
- Unauthorized Access
- Man-in-the-Middle (MitM) Attacks
- Malware and Ransomware
- Denial-of-Service (DoS/DDoS)
- Packet Sniffing

### 5. Network Security Controls
- Authentication and Authorization
- Multi-Factor Authentication (MFA)
- Encryption
- Network Segmentation
- Firewall Configuration
- Access Control
- System Patching
- Network Monitoring
- Backup and Recovery

## 🛠️ Practical Activities

The following activities are included to gain practical knowledge:

- Inspect network configurations using `ipconfig /all`.
- Understand DNS resolution using `nslookup`.
- Examine network routes using `tracert`.
- Inspect HTTPS connections and SSL/TLS certificates.
- Understand basic firewall policies.
- Identify phishing indicators through security awareness exercises.

**Note:** All practical activities should be performed only on systems and networks you own or have explicit permission to assess.
